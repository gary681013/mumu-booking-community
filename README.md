# Mumu Booking Community

一個零依賴、可直接在瀏覽器開啟的預約前端範本，適合美容、治療、諮詢、課程與一對一服務使用。

## 功能

- 手機優先的預約介面
- 60／90／120 分鐘服務範例
- 日期與時段選擇
- 不儲存、不傳送個人資料的示範流程
- 可自行串接 Supabase 或其他後端

## 快速開始

下載或複製 index.html 後，以瀏覽器開啟即可。可部署到 GitHub Pages、Netlify 或 Vercel。

## 隱私與安全

- 請勿提交 API 金鑰、正式資料庫匯出檔或客戶名單。
- 若加入後端，請實作登入、RLS、輸入驗證、預約衝突處理與速率限制。
- 範本只在瀏覽器顯示示範結果，不會送出或保存資料。
